# data/ layout

Real data is NOT committed (see ../.gitignore). Copy these in before starting the server.

```text
data/
  images/                              # candidate/query images, e.g. data/images/test/abc.jpg
  positive_set_input.jsonl             # verification input (rows may carry a "split" field)
  verification/
    users.json                         # create from users.json.example; required to start the server
    split_manifest.jsonl               # only if the input rows have no "split" (see split_manifest.jsonl.example)
    positive_sets_annotator_1.jsonl    # YOU copy the original positive annotations here (read-only for the server)
    positive_sets_annotator_2.jsonl    # generated by Annotator 2
    positive_sets_annotator_3.jsonl    # generated by Annotator 3
    positive_sets_final.jsonl          # generated by the administrator's "Generate" action (majority vote)
    statistics/                        # generated: summary.json, summary.csv, agreement.csv,
                                       #   voting_distribution.csv, per_query.csv, disagreements.csv
```

Setup: `cp /path/to/original/positive_sets.jsonl data/verification/positive_sets_annotator_1.jsonl`, then
`cp data/verification/users.json.example data/verification/users.json` and edit the usernames
(they must match your Nginx Basic Auth accounts). See ../README.md.
